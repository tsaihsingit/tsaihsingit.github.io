# 教室工具箱

程式使用Google Gemini Canvas產生，歡迎自行取用修改。

除了小組計分以及倒數計時，各個工具都會儲存在本機瀏覽器Local Storage內。
整體儲存容量受限於瀏覽器限制，約5MB。黑板工具的圖片請盡量不要放置太大，或是使用網路上的圖片連結，避免超過容量出錯。

每個工具都有返回首頁工具箱的連結，位置不盡相同還請包涵，我也懶得手動修改。

直接使用請開啟： [https://tsaihsingit.github.io/](https://tsaihsingit.github.io/)
